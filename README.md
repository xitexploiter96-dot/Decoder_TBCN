## Overview

**Multi Decoder Pro Max** is a powerful and versatile Python-based tool designed to decode a wide variety of encoded, encrypted, and obfuscated data. It supports multiple encoding formats, ciphers, compression methods, and transformation techniques — all in one place. Perfect for penetration testers, bug bounty hunters, and security enthusiasts who need a quick and reliable decoding solution.

---

## Features

- **Base Encodings:** Base64, Base32, Base16, Base85, Ascii85, Double Base64, Base64 URL.  
- **URL / HTML:** URL Decode, Double URL Decode, HTML Entities, Unicode Escape.  
- **Text Transformations:** Reverse, Reverse Words, Swap Case, Uppercase, Lowercase, Strip Non-ASCII.  
- **Classic Ciphers:** ROT13, ROT5, ROT47, Atbash.  
- **Number Bases:** Hex, Hex Reversed, Binary (with/without space), Binary Reversed, Octal, Decimal ASCII.  
- **Compression:** Zlib, Gzip.  
- **Simple XOR:** XOR-1, XOR-42.  
- **JWT Parsing:** Extract Header and Payload from JWT tokens.  
- **Morse Code:** Decode standard Morse code.  
- **Caesar Ciphers:** Shift by ±1, ±3.  
- **Escapes:** JS `\uXXXX`, HTML Hex Entities.  
- **Auto Decode:** Automatically detect and decode multiple layers of encoding.
